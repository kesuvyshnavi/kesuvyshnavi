### [Veridex](https://github.com/kesuvyshnavi/veridex)
> **AI-Powered Startup Risk Assessment & Strategic Decision Support Platform**

An AI-powered platform that helps founders validate startup ideas before spending money. It analyzes market size, competitors, risk, SWOT and feasibility, then uses a LangGraph agent to generate prioritized strategic recommendations, with secure accounts, a personal dashboard and exportable PDF reports.

- <img src="https://api.iconify.design/lucide:layers.svg?color=%23FF69B4" width="18" height="18" align="absmiddle" alt="" /> **Tech Stack:** HTML • CSS • JavaScript • Node.js • Express • PostgreSQL (Supabase) • Groq API • LangGraph.js • JWT & bcrypt • PDFKit • Render
- <img src="https://api.iconify.design/mdi:github.svg?color=%23FF69B4" width="18" height="18" align="absmiddle" alt="" /> **GitHub:** [kesuvyshnavi/veridex](https://github.com/kesuvyshnavi/veridex)
- <img src="https://api.iconify.design/lucide:globe.svg?color=%23FF69B4" width="18" height="18" align="absmiddle" alt="" /> **Live Demo:** [veridex-ncjj.onrender.com](https://veridex-ncjj.onrender.com) *(hosted on a free tier, so the first load may take about 50 seconds)*
